# Job Hunter — job.ehsannouri.de

شکارچی شغل شخصی برای مهندسی مکانیک/مکاترونیک در آلمان. هر روز ساعت **۱۸:۰۰ (برلین)** اجرا می‌شود،
آگهی‌ها را از چند منبع می‌گیرد، با رزومه‌ی تو مقایسه و امتیازدهی می‌کند، نتیجه را روی `job.ehsannouri.de`
می‌گذارد و بهترین‌ها را در **تلگرام** برایت می‌فرستد.

> ⚠️ این پوشه داخل ریپوی EhsanNouri.de است؛ تا وقتی ریپو عمومی است، `data/state.json` و `site/data/jobs.json` برای همه قابل دیدن‌اند. ریپو را Private کن یا نتایج را از گیت دور نگه دار.

## چطور کار می‌کند

```
منابع ──► dedupe ──► فیلتر عنوان ──► جزئیات آگهی ──► امتیاز قانون‌محور (رایگان)
                                                        │ top 30
                                                        ▼
                                         Gemini Flash (سقف ۰٫۱۰ دلار/روز)
                                                        ▼
              data/state.json ◄── ذخیره ──► site/data/jobs.json ──► rsync ──► job.ehsannouri.de
                                                        ▼
                                                    تلگرام ۱۸:۰۰
```

| منبع | کلید لازم | توضیح |
|---|---|---|
| **Arbeitsagentur Jobsuche** (API رسمی، همان که در پلتفرم پله استفاده شده) | ندارد | بزرگ‌ترین پایگاه آگهی آلمان؛ شرکت‌های کوچک زیادی دارد |
| **Arbeitnow** | ندارد | آلمان‌محور، پر از استارتاپ‌های انگلیسی‌زبان |
| **Remotive** | ندارد | آگهی‌های ریموت (تعداد مکانیکیِ کم) |
| **Adzuna** | `ADZUNA_APP_ID/KEY` (رایگان) | اختیاری؛ بدون کلید رد می‌شود |
| **صفحه‌ی کاریابی خودِ شرکت‌ها** (Greenhouse, Lever, Ashby, Personio) | ندارد | فهرست در `companies.yaml` — بهترین راه برای شرکت‌های کوچک |

LinkedIn عمداً استفاده نشده (شرکت‌های بزرگ و رقابت زیاد، و اسکرپ آن خلاف قوانینشان است).

### امتیازدهی
1. **قانون‌محور (رایگان):** عنوان/مهارت‌های رزومه، انگلیسی‌بودن متن، نشانه‌های استارتاپ، جریمه‌ی شرکت بزرگ،
   کاریابی/Zeitarbeit و الزام آلمانی روان (تو A2 هستی).
2. **هوش مصنوعی (Gemini):** فقط ۳۰ آگهی‌ی برتر؛ دلیل تطابق (EN + FA)، تخمین اندازه/سن شرکت و سطح آلمانی لازم.
   بودجه‌ی روزانه سخت‌گیرانه چک می‌شود؛ هزینه‌ی هر اجرا معمولاً کمتر از ۱ سنت است.
3. امتیاز نهایی = ۰٫۳۵ × قانون + ۰٫۶۵ × AI، با جریمه/جایزه‌ی ثابت.

> اندازه و سن شرکت **تخمین AI** است، نه واقعیت؛ در سایت هم با «≈» نشان داده می‌شود.

## راه‌اندازی (یک‌بار)

### ۱) ریپوی خصوصی
در GitHub یک ریپوی **Private** با نام `job-hunter` بساز (مثلاً زیر `thepelleacademy`) و کد را داخلش push کن.

### ۲) Secrets (Settings → Secrets and variables → Actions)
| Secret | مقدار |
|---|---|
| `GEMINI_API_KEY` | کلید Google AI Studio |
| `TELEGRAM_BOT_TOKEN` | توکن ربات (از @BotFather) |
| `TELEGRAM_CHAT_ID` | آیدی عددی چت خودت (به ربات `/start` بزن، بعد `getUpdates` یا @userinfobot) |
| `SSH_PRIVATE_KEY`, `SSH_KNOWN_HOSTS`, `SSH_HOST`, `SSH_PORT`, `SSH_USER` | همان‌هایی که برای ریپوی EhsanNouri.de استفاده می‌کنی |
| `JOB_DEPLOY_PATH` | مسیر روی سرور، مثلاً `/var/www/job.ehsannouri.de` |
| `ADZUNA_APP_ID`, `ADZUNA_APP_KEY` | اختیاری |

Variable اختیاری: `GEMINI_MODEL` (پیش‌فرض `gemini-2.5-flash`؛ اگر گوگل نام مدل را عوض کرد اینجا عوض کن).

### ۳) سرور (Hetzner)
- DNS: رکورد `A` برای `job` → IP سرور.
- `deploy/nginx-job.ehsannouri.de.conf` را نصب کن (شامل **رمز عبور basic-auth** و noindex)، بعد `certbot`.

### ۴) اولین اجرا
Actions → **Job Hunter (daily 18:00 Berlin)** → *Run workflow*. اولین اجرا ۱۴ روز عقب می‌رود؛ بعدش هر روز ۱۸:۰۰ خودکار.
(کرون گیت‌هاب UTC است؛ دو زمان‌بندی + یک گارد ساعت برلین، تغییر ساعت زمستانی/تابستانی را خودکار پوشش می‌دهد.
گیت‌هاب گاهی چند دقیقه دیرتر اجرا می‌کند.)

## تنظیم دقیق
همه‌چیز در **`profile.yaml`** است: کوئری‌ها، کلیدواژه‌ها، لیست شرکت‌های بزرگ/کاریابی، آستانه‌ها، بودجه‌ی AI.
شرکت‌های مورد علاقه را در **`companies.yaml`** اضافه کن. ظاهر سایت: متغیرهای بالای `site/style.css`.

## اجرای محلی
```bash
pip install -r requirements.txt
python -m pytest -q
python -m hunter run --dry --no-ai      # بدون ذخیره، بدون AI
GEMINI_API_KEY=... python -m hunter run --dry
```

## محدودیت‌های صادقانه
- فرمت پاسخ APIها بر اساس مستندات و کد قبلی پلتفرم پله نوشته شده و **تست زنده از ساندباکس Claude ممکن نبود**
  (دسترسی شبکه‌ی آن محدود است). منطق با داده‌ی نمونه تست شده؛ اگر منبعی خالی برگشت، در لاگ و پیام تلگرام
  با «`<name>: 0 jobs`» گزارش می‌شود و اگر *همه‌ی* منابع خالی باشند workflow قرمز می‌شود.
- در `companies.yaml` هیچ شرکتی از قبل تأیید نشده؛ خودت اضافه کن.
- هر آگهی را قبل از اقدام خودت بخوان؛ AI ممکن است اشتباه کند.
